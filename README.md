# Amazon Sales & Revenue Performance Tracker

Built with Python using real Amazon product data (1,465 products).

## What it does
- Cleans raw Amazon data (prices, ratings, discounts)
- Summarizes performance by product category
- Shows Top 10 most reviewed products
- Bar chart of average price by category

## Files
- cleaning.py — data cleaning script
- build_tracker.py — builds the Excel dashboard
- amazon_tracker.xlsx — final output Excel file

## Tools used
Python, pandas, openpyxl
